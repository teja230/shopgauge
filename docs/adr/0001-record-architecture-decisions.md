---
title: ADR 0001 - Record architecture decisions
status: Accepted
date: 2025-08-13
---

Context
We need a lightweight, versioned process to capture key architectural decisions for StoreSight.

Decision
Adopt Architecture Decision Records (ADRs) using Markdown in `docs/adr/` with incremental numbering.

Consequences
- Improves decision traceability over time
- Enables review in PRs and change history
- Low overhead; easy to maintain
